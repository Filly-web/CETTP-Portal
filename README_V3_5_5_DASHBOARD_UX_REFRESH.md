# CETTP V3.5.5 Dashboard UX Refresh

Extract the ZIP and deploy using the same Render service and PostgreSQL configuration used by the existing CETTP application. No database migration is required for this UI-only release.

The landing page now presents three short workspace choices. Initiator and Tax Compliance dashboards provide shorter summaries and quick links. The EFD Invoice Portal uses shorter guidance text.

Do not reset or recreate the production database. Keep existing Render environment variables and service settings unchanged.

See `CHANGELOG_V3_5_5_DASHBOARD_UX_REFRESH.md` for scope and validation limitations.
