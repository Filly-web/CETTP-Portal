BATCH PROCESSING

Process multiple invoices

Upload Word invoices together, enter the matching TRA verification details for each file, then download all processed documents in one ZIP package. Single-invoice processing remains available separately.

Maximum 100 invoices per batch. Each file must be a valid .docx document. The current portal request limit is 40 MB in total.
Each invoice must have its own verification code and receipt time. The system checks for missing details, repeated filenames and duplicate verification codes before processing. If the batch details are incomplete, no invoices will be processed.
Select your Word invoices above. A matching row for each invoice will appear here.
