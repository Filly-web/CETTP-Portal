# CETTP V3.7.1 Deployment

Deploy this package over the existing V3.7.0 source. Keep the existing Render environment variables and PostgreSQL database. No database migration or reset is required for this route/template correction.

After deployment, sign in as an Initiator and test `/efd-requests/new`, open **Create Digital Invoice**, complete all required fields, generate the Word preview, and confirm that the manual upload option remains available.
